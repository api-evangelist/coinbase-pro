# Coinbase Pro

Coinbase Pro was Coinbase's professional trading platform and API (docs.pro.coinbase.com). It was retired in 2022-2023 in favor of Coinbase Advanced Trade, with the institutional Pro API continuing as the Coinbase Exchange API. Coinbase's current APIs are profiled in the coinbase repository, which is canonical. Consolidated 2026-10-13, approved by Kin Lane.

Canonical profile: [api-evangelist/coinbase](https://github.com/api-evangelist/coinbase) — https://apis.io/providers/coinbase/
